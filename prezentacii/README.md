# Презентации тренинга

Слайды, которые показывали в зале, выложим здесь после тренинга. Обнови базу (`git pull` или свежий архив от бота) - и они появятся.

Пока их нет, содержание блоков есть текстом: [[ponyatiya]] - понятийный блок первого дня, [[raspisanie]] - что в каком блоке, `uroki/` - пошаговые уроки.
