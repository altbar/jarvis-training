# Презентации тренинга

## Что здесь лежит

- **`den1-sozdaem-dzharvisa.pdf`** - слайды первого дня, те самые, что были на экране.
  Понятийный блок, карта моделей, MiniMax, подключение доступа, первые кейсы.

Второй день добавим следом.

## Как этим пользоваться

Открывается любой смотрелкой PDF, ничего ставить не нужно. Но интереснее другое:
**отдай файл своему агенту.** Он читает PDF и умеет отвечать по нему словами.

```
прочитай prezentacii/den1-sozdaem-dzharvisa.pdf и напомни,
что мы говорили про выбор модели
```

Так слайды перестают быть картинками и становятся частью твоей базы: агент
цитирует их, когда ты спрашиваешь по теме тренинга, и связывает с твоими заметками.

## Если нужен текст, а не слайды

- [[ponyatiya]] - понятийный блок первого дня словами
- [[raspisanie]] - что в каком блоке было
- `uroki/` - пошаговые уроки, по ним агент проведёт заново
